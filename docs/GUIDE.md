# Disco Elysium — Український переклад

Український переклад **Disco Elysium: The Final Cut**. Замінює **німецьку** мову: у налаштуваннях обираєте *Deutsch*, а бачите українську.

## Що зроблено
- Діалоги, думки, навички, предмети, інтерфейс, режим Collage — усе перекладено (машинний переклад GPT-4o з невеликими ручними правками).
- Шрифти з кирилицею та українські зображення кнопок/написів.
- Виправлено німецькі написи, які лишалися в грі: назви навичок на аркуші персонажа, «ІНТЕЛЕКТ» (раніше квадрати), екран завантаження.

## Платформи
| Платформа | Статус |
|---|---|
| Windows + Steam | ✅ перевірено |
| Steam Deck / Linux (Proton) | ⚠️ має працювати, не перевірено |
| GOG, Xbox app / Game Pass, Epic | ⚠️ не перевірено |

| Консолі | ❌ неможливо |

## Встановлення (інсталятор)
1. Закрийте гру, розпакуйте архів з інсталятором.
2. Запустіть:
   ```bash
   python installer.py
   ```
   У вікні знайдеться гра (Steam, GOG, Xbox, SD-карта Deck) — натисніть **«Встановити / оновити»**. Теку можна вказати вручну.
3. У грі: **Settings → Language → Deutsch**.

Без графіки: `python installer.py --cli install` (також `info`, `remove`, `--game "ШЛЯХ"`, `--dry-run`).

**Оновлення** — запустіть новий інсталятор поверх старого. **Видалення** — кнопка «Видалити» або `--cli remove`: оригінали повертаються з `_ua_backup`.

**Steam Deck:** Desktop Mode → Konsole → `python3 installer.py` → Game Mode. Тека гри: `~/.local/share/Steam/steamapps/common/Disco Elysium`.

**Xbox / Game Pass:** гра має стояти в теці з правом запису (напр. `X:\XboxGames\Disco Elysium\Content`), після оновлення гри запустіть інсталятор ще раз.

## Ручне встановлення
Скопіюйте з архіву у `…\Disco Elysium\disco_Data\StreamingAssets\AssetBundles\Windows\` теки `lockits`, `images`, `fonts` (спершу зробіть копію). Так залишаться німецькі написи на екрані завантаження та аркуші персонажа — для повного ефекту користуйтеся інсталятором.

## Як це працює
Гра зберігає тексти, зображення й шрифти окремими наборами на кожну мову (Unity AssetBundles). Мод підміняє набір *german* та шрифти. Кілька написів зашито в самі файли гри (`resources.assets`, `level0`, `level2`, `global-metadata.dat`, `collage/shared`) — для них інсталятор застосовує крихітні патчі (bsdiff), а не розповсюджує файли гри.

Безпека: перед змінами перевіряється SHA-256 файлів (невідома версія гри — нічого не чіпає), робляться резервні копії, запис атомарний, гра має бути закрита.

## Відомі проблеми
- Переклад машинний, місцями потребує правок; терміни ще вирівнюються.
- Деякі тексти виходять за межі рамок, на кількох назвах навичок дрібний шрифт.
- Режим дислексичного шрифту не локалізовано.
- Після оновлення гри інсталятор може попередити про невідому версію — запустіть `python installer.py --cli collect-info` і надішліть вивід автору.

## Проблеми?
- Гра німецькою — оберіть Deutsch у налаштуваннях.
- Квадрати замість літер або німецькі написи — надішліть скріншот і місце, де це видно.
- Вильоти — у Steam «Перевірити цілісність файлів», потім інсталятор знову.
