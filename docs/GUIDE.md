# Disco Elysium — Український переклад: повний посібник

Український переклад **Disco Elysium: The Final Cut**. Переклад **замінює німецьку мову** у грі: у налаштуваннях ви обираєте *Deutsch*, а бачите українську.

> Мова Steam/гри не змінюється ні на що інше, російська локалізація не потрібна. Усе, що гра вважає «німецьким» (текст, шрифти, зображення кнопок), у цьому моді — українське.

## 1. Що це і що зроблено

| Частина | Статус |
|---|---|
| Діалоги (~74 000 рядків), думки, навички, предмети, журнал | перекладено (машинний переклад GPT‑4o з російської → українська, далі ручна правка) |
| Інтерфейс, меню, підказки (~8 600 рядків) | перекладено |
| Шрифти з кирилицею (Noto Sans + Minion Pro, як у російській локалізації) | замінено |
| Зображення інтерфейсу (кнопки, написи) | замінено на українські |
| Назви навичок на аркуші персонажа (ЛОГІКА, ЕНЦИКЛОПЕДІЯ…) | виправлено патчем `resources.assets` |
| Напис «ІНТЕЛЕКТ» (раніше — квадрати) | виправлено патчем `level2` |
| Екран завантаження («WIRD GELADEN» → «ЗАВАНТАЖЕННЯ») | виправлено патчем `global-metadata.dat` + розмір шрифту в `level0` |
| Режим Collage (231 рядок) | перекладено, патч `collage/shared` |
| Глосарій (єдині імена, терміни) | застосовано до 176 рядків, продовжується |

### Походження тексту
1. Усі рядки з російської версії перекладено через API (GPT‑4o, рядок за рядком, скриптом на Python).
2. Автор вручну виправляв найгрубіші помилки; триває робота над глосарієм (імена, навички, місця).
3. Вихідний текст перекладу живе в TSV‑файлах (`translation/general.tsv`, `translation/dialogues.tsv`) — його легко правити й порівнювати в git.

## 2. Підтримувані платформи

| Платформа | Статус | Примітка |
|---|---|---|
| **Windows + Steam** | ✅ перевірено автором | основна платформа, на ній тестується інсталятор |
| **Steam Deck / Linux (Proton)** | ⚠️ має працювати, не перевірено | Proton використовує ті самі Windows‑файли гри |
| **Windows + GOG** | ⚠️ не перевірено | файли можуть мати інші хеші → інсталятор зупиниться й покаже хеші (див. `collect-info`) |
| **Windows + Xbox app / Game Pass** | ⚠️ не перевірено | гра в `XboxGames\Disco Elysium\Content`; потрібна можливість запису в цю теку |

| **Консолі (PS/Xbox/Switch)** | ❌ неможливо | файли гри закриті |

«Не перевірено» означає, що я не маю гарантії. Якщо у вас така версія гри — запустіть `collect-info` (розділ 3) і надішліть результат, я додам підтримку.

## 3. Встановлення через інсталятор (рекомендовано)

Інсталятор — один Python‑скрипт (лише стандартна бібліотека) + пакет даних. Він:
- сам знаходить гру (Steam у реєстрі та `libraryfolders.vdf`, GOG, Xbox, SD‑карта Steam Deck; або вказуєте теку вручну);
- перевіряє SHA‑256 кожного файлу гри — якщо версія невідома, **нічого не чіпає**;
- робить резервні копії в `<гра>\_ua_backup\`;
- застосовує крихітні бінарні патчі (bsdiff) до файлів гри та копіює наші бандли;
- записується атомарно (тимчасовий файл → перейменування), перевіряє результат, при помилці скасовує;
- відмовляється працювати, поки гра запущена;
- уміє повністю відкотити зміни.

### Кроки
1. Закрийте гру.
2. Завантажте архів `DiscoElysium_UA_installer_vX.Y.Z.zip` (Nexus Mods / GitHub Releases) і розпакуйте в будь‑яку теку.
3. Запустіть інсталятор:

   **Windows / Linux / macOS (потрібен Python 3.8+ з tkinter):**
   ```bash
   python installer.py
   ```
   Відкриється вікно: шлях до гри (авто), кнопки **«Встановити / оновити»** та **«Видалити (повернути оригінал)»**, журнал і перемикач мови (українська / English).

   **Без графіки (SSH, Steam Deck у Desktop‑режимі без tk, сервер):**
   ```bash
   python installer.py --cli info          # що знайдено
   python installer.py --cli install       # встановити
   python installer.py --cli remove        # відкотити
   ```
   Корисні прапорці: `--game "ШЛЯХ"` (вказати теку гри), `--dry-run` (лише показати, що буде зроблено), `--yes` (без запитань), `--lang uk|en`.

4. Запустіть гру → **Налаштування → Мова → Deutsch**. Усе стане українським.

> Мову гри на німецьку інсталятор **навмисно не перемикає** — це робите ви в налаштуваннях.

### Якщо інсталятор каже «невідома версія гри»
```bash
python installer.py --cli collect-info
```
Скопіюйте вивід (розміри та SHA‑256 файлів) і надішліть автору (коментар на Nexus або issue на GitHub). Раніше ж спробуйте у Steam: *Властивості → Інстальовані файли → Перевірити цілісність* — це повертає оригінальні файли, після чого запустіть інсталятор ще раз.

### Антивірус / SmartScreen / Gatekeeper
- `.exe`‑збірка (якщо буде) не підписана → Windows SmartScreen покаже попередження («Докладніше → Все одно виконати»). Варіант без попереджень — запуск `python installer.py` з вихідним кодом, який можна прочитати (~700 рядків).
- macOS Gatekeeper: `xattr -d com.apple.quarantine <файл>` або запуск через `python3 installer.py`.

## 4. Ручне встановлення

Підходить, якщо не хочете запускати інсталятор. Увага: **повна заміна лише трьох бандлів не виправляє все** — решта виправлень лежить у файлах гри (див. розділ 7), тому ручний шлях дає «класичну» версію з відомими німецькими написами (екран завантаження, назви навичок на аркуші).

1. Закрийте гру та **зробіть копію** теки `AssetBundles\Windows`.
2. Скопіюйте з архіву з перекладом (зі збереженням структури) у
   ```
   <Steam>\steamapps\common\Disco Elysium\disco_Data\StreamingAssets\AssetBundles\Windows\
   ```
   такі файли:
   - `lockits\german` — весь текст;
   - `images\german` — зображення інтерфейсу;
   - `fonts\english` — шрифти з кирилицею.
3. Запустіть гру, у налаштуваннях оберіть **Deutsch**.

Повернення: поверніть свою копію або «Перевірити цілісність файлів» у Steam.

Для повного вигляду (без німецьких написів) потрібні ще патчі файлів `resources.assets`, `level0`, `level2`, `global-metadata.dat`, `collage\shared` — вручну їх не накласти, використовуйте інсталятор.

## 5. Встановлення на різних платформах

### Windows — Steam
Тека гри за замовчуванням: `C:\Program Files (x86)\Steam\steamapps\common\Disco Elysium`. Якщо гра на іншому диску — шлях бачите в Steam: *ПКМ на грі → Керувати → Переглянути локальні файли*. Інсталятор знаходить бібліотеки Steam сам.

### Windows — GOG
Типовий шлях: `C:\GOG Games\Disco Elysium` або `...\GOG Galaxy\Games\Disco Elysium`. Вкажіть теку вручну кнопкою «Обрати…» (у ній має бути `disco_Data`). Якщо хеші не збігаються — `collect-info`.

### Windows — Xbox app / Game Pass for PC
Гру можна ставити в теку на вибір, зазвичай `X:\XboxGames\Disco Elysium\Content`. У старих налаштуваннях Xbox app файли в `WindowsApps` захищені від запису — перевстановіть гру в `XboxGames` або вкажіть іншу теку встановлення. Оновлення Xbox може перезаписати файли → запустіть інсталятор ще раз.

### Steam Deck / Linux
Нативної Linux‑версії немає: гра працює через **Proton**, а файли ті самі, що й у Windows. Тека гри:
```
~/.local/share/Steam/steamapps/common/Disco Elysium
```
(на SD‑карті: `/run/media/<id>/steamapps/common/Disco Elysium`).

1. Перейдіть у **Desktop Mode** (кнопка Steam → Живлення → Режим робочого столу).
2. Розпакуйте архів, відкрийте Konsole у теці з інсталятором.
3. `python3 installer.py` (Python є в SteamOS) або `python3 installer.py --cli install`.
4. Поверніться в Game Mode, запустіть гру, оберіть Deutsch.

Якщо у вікні немає tkinter — інсталятор сам переходить у текстовий режим (`--cli`).

### macOS (нативна)
Поки що **не підтримується**: файли гри на Mac відрізняються (інші бандли та метадані), для них потрібен власний набір патчів, зібраний із Mac‑оригіналів. Автор планує це перевірити на власному Mac. Як ви можете допомогти — запустіть `python3 installer.py --cli collect-info` і надішліть вивід.

### Консолі
PlayStation, Xbox, Nintendo Switch — встановити сторонні моди неможливо.

## 6. Оновлення та видалення

- **Оновлення перекладу** — просто запустіть новий інсталятор поверх старого. Він спочатку відновлює оригінали з `_ua_backup\`, потім накладає нову версію, тож зайвого не залишається. Автооновлення немає.
- **Видалення** — кнопка «Видалити (повернути оригінал)» / `--cli remove`. Усі змінені файли повертаються, тека `_ua_backup` видаляється.
- **Після оновлення гри Steam/GOG/Xbox** файли можуть змінитися (хеші не збіжаться) → інсталятор попередить; зачекайте на нову версію перекладу або надішліть `collect-info`.
- **Модифікація вручну + інсталятор:** якщо раніше ставили мод руками, у Steam запустіть перевірку цілісності, потім інсталятор — інакше він не матиме чистих оригіналів («резервної копії інсталятора немає»).

## 7. Як це працює всередині

### 7.1. Чому «німецька»
Disco Elysium зберігає тексти в **I2 Localization lockit‑ах** — Unity AssetBundle‑файлах у `disco_Data\StreamingAssets\AssetBundles\Windows\`. Для кожної мови є свій набір: `lockits\<мова>`, `images\<мова>`, `fonts\<мова>`. Мод замінює набір *german* (текст, зображення) і підміняє шрифти в `fonts\english`, щоб гра вмикала шрифти з кирилицею. Так не потрібна російська мова в Steam, а гра не «знає», що вона українською.

### 7.2. Що де лежить

| Файл (відносно `disco_Data`) | Що містить | Як ставиться |
|---|---|---|
| `StreamingAssets\AssetBundles\Windows\lockits\german` | `DialoguesLockit` (~74 000 термінів) і `GeneralLockit` (~8 600 термінів) | повна заміна |
| `…\images\german` | текстури кнопок, написів | повна заміна |
| `…\fonts\english` | TMP SDF‑шрифти (Noto Sans, Minion Pro) з кирилицею | повна заміна |
| `…\collage\shared` | `CollageModeLockit` (режим Collage, 231 рядок) | патч bsdiff |
| `resources.assets` | `CharsheetSkillLabelsGerman` — назви навичок на аркуші персонажа | патч bsdiff |
| `level2` | позначка INT («ІНТЕЛЕКТ») — прибрано пряме посилання на шрифт без кирилиці | патч bsdiff (3 байти) |
| `level0` | розмір шрифту на стартовому екрані | патч bsdiff (2 байти) |
| `il2cpp_data\Metadata\global-metadata.dat` | рядок `WIRD GELADEN` зашитий у код | патч bsdiff |

### 7.3. Чому патчі, а не готові файли
Файли гри (`resources.assets`, `level*`, метадані) належать розробникам. Інсталятор **не розповсюджує їх**: у пакеті лежать лише різниці (bsdiff від 154 байтів до ~90 КБ), які застосовуються до вашого локального оригіналу. Перед цим перевіряється SHA‑256 оригіналу — тож патч не ляже на іншу версію гри. Наші власні бандли (`lockits/german`, `images/german`, `fonts/english`) — це наш контент, вони йдуть як є.

### 7.4. Безпека інсталяції
1. Усе обчислюється в пам’яті й перевіряється за хешем ДО запису.
2. Резервні копії в `_ua_backup\` + `install.json` (версія мода, список файлів).
3. Запис атомарний; після запису ще раз перевіряється хеш.
4. Гра не запущена (перевірка процесу `disco.exe`).
5. `--dry-run` показує дії без змін.

### 7.5. Де «ховалися» німецькі написи (цікаве для моддерів)
- **Навички на аркуші** — не в lockit, а в MonoBehaviour `CharsheetSkillLabelsGerman` (`resources.assets`, path_id 3005), без typetree; формат розібрано вручну (`tools/patch_skill_labels.py`).
- **«WIRD GELADEN»** — не текстура і не lockit, а літерал C# у IL2CPP‑метаданих; новий текст дописується в кінець файлу, а запис у таблиці літералів перенаправляється.
- **Квадрати на «ІНТЕЛЕКТ»** — компонент I2 Localize мав прямий PPtr на шрифт `Dobra‑Book SDF` без кирилиці.
- Шрифти обираються через `FontsLockit<Lang>` (термін → ім’я font asset на мову).
- Деталі та path ID — у `docs/findings.md`.

### 7.6. Репозиторій
```
translation/        джерело правди: general.tsv, dialogues.tsv
tools/              скрипти (патчі, експорт, збірка пакета, тести)
installer/          installer.py
docs/               findings, glossary, installer-spec, цей посібник
```
Збірка пакета: `python -I tools/build_package.py --version X.Y.Z` → `dist/DiscoElysium_UA_installer_vX.Y.Z.zip`.

## 8. Відомі проблеми
- Переклад машинний, місцями потребує редагування; терміни ще вирівнюються за глосарієм.
- Окремі тексти виходять за межі рамок (напр. «ПЕРСОНАЖ» у нижній панелі переноситься).
- Деякі шрифти без `Є І Ї Ґ` (CoreSansES Light SDF) — виправлено лише для використаних написів.
- Малі розміри шрифту на кількох назвах навичок (Тремтіння, Навіювання, Самовладання, Електрохімія, Координація).
- Режим Collage перекладено, але в грі ще не перевірено на квадрати й переповнення.
- Режим дислексичного шрифту (`images_dyslexic`) не локалізовано — зображення там німецькі.
- Після оновлення гри патчі можуть перестати накладатися (див. розділ 6).

Список задач — `TASKS.md`.

## 9. Вирішення проблем

**Гра запускається німецькою / нічого не змінилося.** У грі: *Settings → Language → Deutsch* (перезапуск гри інколи потрібен).

**Квадрати замість літер.** Шрифт без кирилиці. Зробіть скріншот і надішліть місце (мені потрібні назва екрана та рядок).

**Німецькі написи («WIRD GELADEN», навички) залишились.** Ви поставили лише три бандли вручну; використайте інсталятор.

**Гра вилітає при запуску.** `Steam → Перевірити цілісність файлів` (повертає оригінал) → інсталятор. Прикріпіть `Player.log` з `%USERPROFILE%\AppData\LocalLow\ZAUM Studio\Disco Elysium\`.

**«Гра запущена».** Закрийте Disco Elysium (перевірте Диспетчер завдань).

**«Невідома версія гри».** Розділ 3 — `collect-info`.

**tkinter відсутній.** Використовуйте `--cli`. На Debian/Ubuntu: `sudo apt install python3-tk`.

**Хочу тимчасово повернути оригінал.** `--cli remove`, потім знову `install`.
