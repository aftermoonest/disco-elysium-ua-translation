# Disco Elysium — український переклад: інсталятор

Цей інсталятор ставить український переклад Disco Elysium — The Final Cut. Переклад підміняє **німецьку** мову гри
(щоб не користуватися російською в Steam), тож після встановлення в налаштуваннях гри треба обрати **Deutsch**.

Інсталятор:
- перевіряє, що у вас підтримувана версія гри (за контрольними сумами файлів);
- зберігає оригінальні файли в теці `_ua_backup` у папці гри;
- змінює лише потрібні файли (дрібні патчі + файли перекладу);
- дозволяє повністю **видалити** переклад і повернути гру як було;
- оновлюється просто повторним запуском нової версії.

## Що підтримується

| Платформа | Стан |
|---|---|
| Windows, Steam | перевірено |
| Steam Deck / Linux (Steam, Proton) | має працювати (ті самі файли, що й у Windows), чекаємо відгуків |
| Windows, GOG / Xbox-застосунок (Game Pass) / Epic | інсталятор перевірить версію й підкаже; якщо файли відрізняються, див. «Інша версія гри» |
| macOS, Steam (Apple Silicon, macOS 26) | перевірено (інсталятор і гра). Intel Mac і старіші macOS не перевірялися |
| Консолі (Xbox, PlayStation, Switch) | неможливо |

## Встановлення

### Windows
1. Розпакуйте архів у будь-яку теку (**не** запускайте з архіву). Тека `package` має лежати поруч з `.exe`.
2. Закрийте гру. Запустіть `DiscoElysium_UA_installer.exe`.
3. Якщо Windows показує «Windows захистила ваш ПК» (SmartScreen): натисніть «Докладніше» → «Все одно виконати».
   Програму не підписано цифровим підписом. Її код — звичайний скрипт Python (`installer.py`), який можна прочитати.
4. Натисніть **«Знайти гру»** (або **«Обрати…»**, якщо гру не знайдено), потім **«Встановити / оновити»**.

### Steam Deck
1. Перейдіть у Desktop Mode (Steam → Живлення → Перейти в режим робочого столу).
2. Завантажте та розпакуйте архів «python» (див. нижче), відкрийте теку в Dolphin, у меню «Відкрити термінал тут».
3. Виконайте: `python3 installer.py` (відкриється вікно) або `python3 installer.py --cli install`.
   Гра на Deck працює через Proton, тож файли ті самі, що й у Windows.

### Linux
Те саме, що й для Steam Deck: `python3 installer.py` у теці з розпакованим архівом.
Якщо вікно не відкривається (немає `python3-tk`), користуйтесь текстовим режимом: `python3 installer.py --cli install`.

### macOS
1. Відкрийте Термінал у розпакованій теці й виконайте: `python3 installer.py`
   На macOS 26 вікно Tk у системному Python аварійно закривається (повідомлення «macOS 26 (2603) or later required»).
   Інсталятор це розпізнає й сам переходить у текстовий режим: просто підтвердіть встановлення `y`.
   Видалити переклад: `python3 installer.py --cli remove`.
2. Якщо macOS блокує файл: `xattr -d com.apple.quarantine installer.py`.
3. Підтримується Steam-версія (`~/Library/Application Support/Steam/steamapps/common/Disco Elysium`). Гра не повинна бути запущена.
   Якщо інсталятор напише «Невідома версія гри», див. нижче.

## Після встановлення
Запустіть гру й у налаштуваннях мови оберіть **Deutsch**. Усі тексти будуть українською.

## Видалення
Запустіть інсталятор і натисніть **«Видалити (повернути оригінал)»**. Резервні копії повернуться на місце, тека `_ua_backup` зникне.

## Оновлення
Просто запустіть інсталятор нової версії та натисніть **«Встановити / оновити»**. Резервні копії оригіналів залишаються тими самими.

## Текстовий режим
```
python3 installer.py --cli info            показати, що знайдено
python3 installer.py --cli install         встановити (запитає підтвердження; --yes без запиту)
python3 installer.py --cli remove          видалити
python3 installer.py --cli install --dry-run   нічого не змінювати, лише показати кроки
python3 installer.py --cli collect-info    контрольні суми файлів гри (для звіту)
python3 installer.py --game "ШЛЯХ" ...     вказати теку гри вручну
python3 installer.py --lang en             англійський інтерфейс
```
У Windows замість `python3 installer.py` пишіть `DiscoElysium_UA_installer.exe`.

## Проблеми

**«Невідома версія гри»**: файли гри не збігаються з жодною відомою версією. Нічого не змінено. Що робити:
1. У Steam: Disco Elysium → Властивості → Інстальовані файли → **Перевірити цілісність файлів**, потім запустіть інсталятор знову.
2. Якщо гра з іншого магазину (GOG, Xbox, Epic) або Mac: запустіть `--cli collect-info` і надішліть результат автору
   (так ми додамо вашу версію).

**«Файли гри вже містять переклад, але резервної копії немає»**: переклад ставили вручну. Перевірте цілісність файлів
у Steam (див. вище) і встановіть через інсталятор.

**«Гра запущена»**: закрийте Disco Elysium.

**Steam оновив гру або «перевірив файли»**: переклад міг злетіти. Встановіть його знову.

**Квадратики або німецький текст**: переконайтесь, що в налаштуваннях гри обрано Deutsch, і напишіть, де саме це видно (скріншот).

## Для розробників
Пакет складається зі скрипта `installer.py` і теки `package/` (`manifest.json`, `patches/*.bsdiff`, `data/`). Інсталятор
не потребує сторонніх бібліотек (лише Python 3.8+). Змінені файли гри не розповсюджуються: у пакеті лише
бінарні різниці (bsdiff) відносно оригіналів, перевірені за SHA-256.
